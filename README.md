# 掘金头条后端项目
## 项目简介
基于FastAPI开发的新闻资讯后端接口，实现新闻分类、新闻分页查询、收藏、浏览历史等功能，引入Redis缓存优化查询性能，统一异常处理、跨域配置，适配前端页面调用。

## 技术栈
- 语言：Python 3.10+
- 框架：FastAPI
- ORM：SQLAlchemy
- 数据库：MySQL 8.0
- 缓存：Redis
- 其他：Pydantic、CORS跨域

## 功能模块
- 新闻分类：分类查询、分类缓存
- 新闻列表：分页查询、Redis缓存热点列表
- 收藏功能：新闻收藏、取消收藏
- 浏览历史：记录用户浏览记录
- 全局异常捕获、统一返回格式
